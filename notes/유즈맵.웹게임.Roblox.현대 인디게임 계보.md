# 🔥 11. 네 방향에서 특히 강한 포인트

## 너는 이런 조합을 잘 잡고 있음

```text
유즈맵 감성
+ 웹 기반
+ 빠른 몰입
+ 중독 루프
+ 다크 감성
+ 시스템 중심
```

이 조합은 생각보다 희귀해.

왜냐면 대부분:

* 감성만 있거나
* 시스템만 있거나
* 기술만 있는데

너는:
“유즈맵 감성 + 시스템 중독성”
쪽을 계속 파고 있거든.

그게:

* Spike Zero
* CloverPit 스타일
* 레이더 분류 게임
* 웹 리듬류

전부에서 공통적으로 보임.
