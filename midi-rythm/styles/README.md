# Style Modules

`base.css`
- Fonts, CSS variables, reset rules, shared body/background treatment, common button/input defaults.

`layout.css`
- Main HUD cards, loader panel, typography blocks used by the main layout shell.

`game.css`
- Judge text, combo HUD, fever overlays, fever stage color changes, result screen, gameplay responsive tweaks.

`editor.css`
- Chart toggle button, chart panel, export area, in-game editor timeline and responsive editor layout.

## Change guide

- Global palette or shared button feel: edit `base.css`
- Loader, left/right HUD, shell spacing: edit `layout.css`
- Combo, fever, result, gameplay-only visual feedback: edit `game.css`
- Chart panel or in-game note editor UI: edit `editor.css`
